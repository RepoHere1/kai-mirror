Strategy

What this system does

the trading pipeline

Kai-Mirror scans prediction markets, asks an LLM whether each contract is mispriced, sizes a position with fractional Kelly sizing, then manages exits with stop-loss, take-profit and time-based rules. Every scan is recorded in SQLite — that is what the numbers on this page are read from.

  1. Ingest — pulls open markets from the Kalshi API and upserts prices into markets.
  2. Decide — scores each eligible market with an LLM pass via OpenRouter, under a daily cost budget.
  3. Execute "” sizes with full-Kelly and places orders, with price-sanity and fail-closed balance checks.
  4. Track — monitors open positions and closes them on stop-loss, take-profit, time or resolution, writing each close to trade_logs.
  5. Evaluate — aggregates realized P&L, win rate and per-strategy attribution.
python cli.py run --paper --dry Live trading additionally needs LIVE_TRADING_ENABLED=true.
